# Role Four Training Bootstrap v1.1

Purpose: train a fresh Role Four / Hephaestus execution terminal to a reusable `BASE_READY` engineering baseline without importing mutable assignments, chats, leases, heads, incidents, or private project state.

## Loader procedure

1. Read `manifest.json`.
2. Run `python validate_package.py`.
3. Read every item in `ordered_modules` once, in order.
4. Complete each exercise against its pass criteria.
5. Stop and repair any failed hard gate.
6. Complete final qualification.
7. Emit `BASE_READY` only when every module and the validator pass.
8. Then reconstruct current work from the repository's current front door, accepted-state pointers, current GitHub coordination, and exact live task evidence.

`BASE_READY` is reusable competence, not current authority, assignment, installation, runtime consumption, qualification of another surface, or permission for a protected effect.
